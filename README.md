# 차근 1.4 — 그룹 기능

기존 차근 1.3에서 `친구`와 `설정` 사이에 `그룹` 메뉴를 추가했습니다.

## 핵심 사용 방식
- 그룹 이름을 정해 생성합니다. 그룹을 만든 사용자는 관리자입니다.
- 기존 친구 메뉴의 16자리 코드를 입력해 상대방을 그룹에 초대합니다. 기존 1:1 친구가 아니어도 초대할 수 있습니다.
- 상대방이 `그룹 → 받은 그룹 초대 → 참여`를 눌러야 그룹원이 됩니다. 수락 전에는 데이터가 공개되지 않습니다.
- 승인된 그룹원 모두가 서로의 오늘 공부 시간·현재 공부 상태·최근 접속을 보며, 그룹별 공부 시간 순위를 확인합니다.
- **친구 메뉴의 기존 순위**에도 그룹원이 함께 포함됩니다. 다만 실제 1:1 친구 링크를 자동으로 추가하지는 않습니다.
- 그룹원 관계는 날짜가 바뀌어도 유지되고, 사용자·관리자는 그룹 탈퇴·멤버 내보내기·그룹 삭제를 할 수 있습니다.
- 관리자는 다른 승인된 그룹원에게 관리 권한을 이전할 수 있습니다.
- 그룹 인원 수에 별도의 애플리케이션 제한을 두지 않았으며, 순위 목록은 15명씩 페이지를 나누어 봅니다. 다만 서비스 운영 용량·성능 제한은 별개입니다.

## 개인정보 공유 범위
- 친구 탭의 `오늘 공부 시간 공유` 설정이 그룹에도 똑같이 적용됩니다. 공유를 끄면 그룹원의 순공 시간과 공부 상태도 볼 수 없습니다.
- 개인별 할 일, 학교 시간표, 과거 날짜의 상세 기록, 이메일, 개인 설정은 노출되지 않습니다.
- 그룹원 관계는 1:1 친구 관계를 따로 만들지 않기 때문에, 그룹에서 나가거나 그룹이 삭제되면 그 그룹을 통한 열람 권한도 사라집니다. 별도로 맺은 1:1 친구는 유지됩니다.

## 설치 순서 — SQL 먼저, GitHub 나중
1. Supabase SQL Editor에서 `02_RUN_IN_SUPABASE/003_groups.sql` 내용을 **모두 붙여넣고 Run** 합니다. 001·002가 이미 적용되어 있어야 합니다.
2. `01_UPLOAD_TO_GITHUB_ROOT` 안의 파일과 폴더를 GitHub 리포지토리 루트로 업로드합니다. **ZIP 자체를 업로드하면 안 됩니다.**
3. GitHub Actions에서 build/deploy가 초록색인지 확인하고 차근에서 새로고침합니다.
4. 그룹 메뉴에서 테스트 그룹을 만들고, 다른 계정으로 수락하면 서로의 기록 공유를 확인할 수 있습니다.

## 안정성·검사 범위
- 기존 `study_workspaces`, 개인 기록, 계정, 1:1 친구 관계 및 시간표 데이터는 변경·초기화하지 않습니다.
- 앱 코드의 TypeScript/TSX 문법 검사 및 로직 테스트 통과. 단, 실제 Supabase SQL 적용과 전체 Next.js 빌드는 이 환경에서 확인하지 못했으므로 배포 뒤 검증이 필요합니다.
