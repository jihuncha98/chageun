# 차근 · 3단계 업데이트 (2026-11-04)

기존 차근 앱의 **오늘·타이머·학교 시간표·Supabase 연동을 유지**하며 시험 D-day와 달력 계획을 추가한다.

## 3단계 기능

- 오늘 화면 맨 위: 가장 가까운 시험 D-day (한국 시간 자정에 변경)
- 시험 대비: 시험 추가/수정/휴지통 이동, 지나간 시험 D+N
- 달력: 이전 달/다음 달/오늘로, 날짜 선택, 계획 개수 및 완료 개수
- 계획: 선택 날짜의 과목·내용 입력, 수정, 완료 체크, 휴지통
- 진행률: 선택 날짜 전체 및 과목별 **완료한 할 일 수 / 그날 계획한 할 일 수**
- 같은 할 일 데이터를 사용하므로 오늘 화면의 할 일과 달력 계획은 서로 반영된다.

## 기존 앱 갱신

1. 이번 패키지의 `01_UPLOAD_TO_GITHUB_ROOT` 폴더 **내부 내용**을 `jihuncha98/chageun` 저장소의 최상위(`main`)에 업로드해 같은 경로 파일을 덮어쓴다. ZIP 파일 자체를 올리면 안 된다.
2. GitHub의 `Actions`에서 Pages 빌드 및 배포가 통과했는지 확인한다.
3. https://jihuncha98.github.io/chageun/ 접속 후 `Ctrl + Shift + R` 또는 아이패드에서 새로고침한다.
4. `시험 대비`에서 시험과 계획을 하나씩 추가한 후 `오늘`에서도 D-day/할 일을 확인한다.

**Supabase SQL Editor에서 실행할 SQL은 없다.** 버전 001의 `study_workspaces.data`는 JSON 형태여서 이번에 추가한 `exams` 필드를 그대로 저장한다. 기존 데이터와 사용자 계정은 초기화하지 않는다.

## 검증 범위

로직·기기 저장소 회귀 테스트 28개와 TypeScript 순수 로직 타입 검사를 이 작업 환경에서 통과했다. 완전한 `npm ci`, Next.js 빌드/린트, 실제 브라우저 렌더링은 패키지 내려받기 불가로 이 환경에서 실행하지 못했다. GitHub Actions의 검사 결과를 최종 확인해야 한다.

## 개발 환경 (기존 설정 그대로)

`npm ci`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`. 기존 `.github/workflows/pages.yml`과 Supabase 환경 변수는 변경하지 않는다.
