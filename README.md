# 차근 · 친구 기능 업데이트 (2026-11-04)

앞서 GitHub Actions 초록색 체크가 확인된 3단계 버전에서 이어지는 **친구 기능 (4A 단계)** 업데이트다. 원래 학습 계획의 오답노트·암기 카드는 4B로 이어간다.

## 새로운 기능
- 별명과 랜덤 16자리 친구 코드를 만들고 복사한다. 이메일 및 인증 정보는 친구 화면에 공개하지 않는다.
- 코드로 요청 보내기 → 상대방 수락 또는 거절 → 친구 목록 추가. 친구 요청 취소/친구 삭제 지원.
- 오늘의 순공 시간을 **한국 시간 06:00~다음 날 06:00** 기준으로 서버가 계산한다. 공부 기록 수정·삭제·공부 타이머가 반영된다.
- 나와 승인한 친구만 순위에 표시한다. 동점은 공동 순위(1,1,3), 비공개는 순위 없음.
- 최근 3분 이내 차근 접속이 확인되고 공부 타이머가 실행 중일 때만 `공부 중`으로 보인다. 약 45초마다 조회한다.
- **서로 공유가 켜져 있을 때만** 오늘 공부 시간·공부 중 여부·최근 접속을 공개하며, 언제든 공유를 끌 수 있다.
- 개인 할 일, 학교 시간표, 과거 날짜 기록, 오답 사진, 이메일, 원본 공부 세션을 친구에게 제공하지 않는다.

## 적용 방법 — SQL 먼저, 파일 업로드 나중

1. Supabase 프로젝트의 **SQL Editor → New query**에서 배포 ZIP 안의 `02_RUN_IN_SUPABASE/002_friends.sql` 전체를 붙여 넣고 **Run**을 누른다. `Success. No rows returned` 또는 오류 없는 성공을 확인한다. **기존 001 SQL을 다시 실행하거나 테이블을 삭제하지 않는다.**
2. GitHub의 `jihuncha98/chageun` 저장소 → **Add file → Upload files**에서 ZIP 안의 **`01_UPLOAD_TO_GITHUB_ROOT` 폴더 내부 파일 및 폴더만** 저장소 최상위 경로로 업로드한다. 같은 경로 파일은 새 버전으로 변경한다. ZIP 자체를 올리지 않는다.
3. **Commit changes** → **Actions** 초록색 체크를 확인한다.
4. https://jihuncha98.github.io/chageun/ 에서 강력 새로고침 후 **친구** 탭을 연다. 본인 별명을 설정하고 코드를 확인한다.
5. 다른 계정도 친구 탭을 열어 자기 코드를 만든 뒤 코드를 교환한다. 요청과 수락 후 순위·공개 전환을 확인한다.

## 기존 자료 보호

`002_friends.sql`은 `friend_profiles`, `friend_links`라는 **새 테이블만 생성**하고 제한된 서버 함수를 추가한다. `study_workspaces` 내용과 로그인 계정, 시간표, 시험 계획, 공부 기록을 변경하지 않는다. 기존 비공개 공부 기록을 읽는 공개 SQL 권한은 추가하지 않는다.

## 검사와 확인되지 않은 부분

친구 순위/시간/코드 관련 순수 함수 테스트 4개 통과, 새 TSX의 구문 검사 통과, 친구 순수 로직의 TypeScript 타입 검사 통과. 이 환경은 `node_modules`가 없어 전체 Next.js 빌드·ESLint·실제 Supabase SQL 실행을 확인하지 못했다. GitHub Actions와 두 계정의 실제 승인 절차로 검증해야 한다. **SQL Editor가 오류를 출력하면 그대로 복사해 전달한다.**
