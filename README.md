# 차근 1.3 — 측정 기록 목록·페이지 나누기·이름 설정 화면 전환 개선

## 변경 사항
- **오늘**: 오래 쌓일 수 있는 ‘측정 기록 목록’ 섹션 제거. 타이머, 오늘의 할 일, 실제 기록 타임라인과 직접 기록 추가/수정 기능은 유지.
- **통계**: 모든 날짜의 측정 기록을 최신 순으로 정렬해 **페이지당 7개** 표시. 1~5 등의 페이지 번호와 처음/이전/다음/끝 이동 제공. 날짜별 필터 추가.
- 기록 목록에서 **시간 수정, 종료, 휴지통** 기능 사용 가능. 기존 중복 기록/충돌 해결 흐름 유지. 통계의 7일·30일 그래프와 별개로 기록 전체를 조회.
- **설정 > 내 이름 설정**: 기존에 전체 화면의 별도 위치에 조건부 렌더링되던 화면을 설정 탭의 전용 영역으로 이동. 탭을 전환할 때 컴포넌트가 확실히 언마운트되도록 화면 경계를 구분함. 저장한 이름은 기존 Supabase 사용자 메타데이터에 계속 저장.
- 모바일 기록 행 및 페이지 버튼 레이아웃 보완.

## 설치
1. ZIP 다운로드 후 압축 풀기.
2. `01_UPLOAD_TO_GITHUB_ROOT` 폴더 **안의 내용**을 GitHub 저장소 `jihuncha98/chageun`의 **루트**에 경로를 유지한 채 업로드.
3. `Commit changes` 후 GitHub Actions `build`/`deploy` 초록색 확인.
4. 웹앱에서 강력 새로고침(Ctrl+Shift+R). `통계 > 측정 기록 목록`, `설정 > 이름 저장 > 오늘` 메뉴 전환 확인.

## 데이터 보호
- Supabase SQL 재실행 불필요. 데이터 구조 변경, 초기화, 기록 삭제 작업 없음.
- 기존 기록의 합산과 동기화 로직은 그대로 사용.
- 최근 로그인/화면 기반의 실제 기기 동작은 GitHub 배포 후 확인 필요.

## 검사
- 로직 테스트 53개 통과(기존 49개 + 페이지 나누기 테스트 4개).
- 수정한 TSX/TS 파일 TypeScript 문법 변환 검사 통과.
- 정적 화면 샘플에 대해 브라우저 너비 320, 375, 430, 768, 1056, 1440px에서 가로 넘침 및 기록 버튼 겹침 없음.
- 전체 Next.js 빌드는 외부 패키지가 없는 작업 환경에서 실행하지 못했으므로 GitHub Actions에서 최종 확인할 것.
