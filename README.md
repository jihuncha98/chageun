# 차근 – 현재 시각·화면 겹침·꾸미기 업데이트 (2026-11-04)

## 수정 사항
- **오늘** 화면에 초 단위로 갱신되는 한국 시각과 날짜를 눈에 띄게 표시합니다.
- 학습일 입력칸과 ‘오늘’ 버튼이 겹치던 문제를 유연한 레이아웃으로 고쳤습니다. 작은 화면의 달력, 양식, 기록 목록, 순공 카드, 친구 화면까지 최소 너비·줄바꿈 규칙을 보강했습니다.
- **시험 대비**에서는 기존 날짜별 계획·완료 수를 유지하고, 중복 정보인 **과목별 진행률** 섹션만 제거했습니다. 실제 공부 기록과 통계는 그대로 유지합니다.
- **설정**의 ‘과목 관리’ 화면은 제거했습니다. 할 일·시험 대비에서 과목 이름을 입력하면 자동으로 만들고, 과거에 보관했던 과목 이름을 다시 사용하면 활성화됩니다.
- **설정 → 나만의 차근 꾸미기**에 라이트/다크, 블루·라벤더·민트·코랄 테마, 기본·명조·둥근 고딕 글꼴 선택을 추가했습니다. 테마·글꼴은 기기 브라우저별 localStorage에 기억됩니다(기기 간 동기화 아님). 글꼴은 설치된 시스템 글꼴에 따라 다르게 보일 수 있습니다.
- 친구 관계는 원래부터 DB에 영구 보존되고, ‘내 친구 → 친구 삭제’ 기능이 존재합니다. 날짜 경계에서는 공부 순위·학습 기록 합산만 새로 시작합니다. 이 부분의 SQL은 변경하지 않았습니다.

## GitHub 업데이트
압축을 푼 뒤 `01_UPLOAD_TO_GITHUB_ROOT` 폴더 **안의 파일/폴더**를 저장소 루트로 업로드하고 Commit합니다. **Supabase SQL 변경 없음.** 기존 기록 삭제나 테이블 초기화 금지.
